:::note[Official MailCraft sites]
MailCraft's official homes are the [MailCraft website](https://mailcraft.work/) and the [MailCraft repository on GitHub](https://github.com/UCSLabs/mailcraft). Other projects with a similar name are not MailCraft.
:::

MailCraft is free and open source under the MIT licence, written from scratch in Rust. It is in public beta and runs on Windows, macOS, Linux and FreeBSD.

## Get help

- **Help and support:** start with [MailCraft support](https://mailcraft.work/support/).
- **Documentation:** read the [MailCraft documentation](https://mailcraft.work/docs/) on the MailCraft website, or the guides on this wiki.

## Report a bug or request a feature

Open an issue on the [MailCraft issue tracker](https://github.com/UCSLabs/mailcraft/issues). Search the existing issues first in case someone has already reported it.

## Download MailCraft

Get the latest release from [MailCraft downloads](https://mailcraft.work/personal/download/). For installing and updating, see [Install and update](/apps/mailcraft/install-update/).

## Organisations

For deployment and support in your organisation, contact [MailCraft for Business](https://mailcraft.work/contact/).

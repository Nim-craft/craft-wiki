## Ask what it can do

Start a new chat or session and ask:

> What can you do with WordCraft?

Use your own app's name. The assistant should describe the app's tools. If it says it can't see the app, go back to the "Check it's connected" part of your assistant's page in Step 2.

## Give it a first task

Start small, and name the folder to work in. For example:

- **WordCraft**: *"Write a one-page project brief and save it as brief.docx in my Documents folder."*
- **GridCraft**: *"Make a monthly budget in budget.xlsx with a total row."*
- **VectorCraft**: *"Draw a simple logo with a blue circle and the word Hello, and export it as logo.svg."*

Most Craft apps work in the background, with no window, so you won't see the app open. When the assistant is done, open the file it made to check it.

## Saying yes to the tools

Most assistants ask before they use a tool, showing its name and what it will be given. Read it, then allow it once, or for the rest of the chat. Say no if it's about to do something you didn't ask for.

## Tips for better results

- **Be specific.** Say what you want, which file and folder to use, and what it should be called.
- **Ask it to check.** *"Check the result and fix anything that's wrong"* helps, since the apps let the assistant read back its own work.
- **Work in steps.** For a big job, ask for an outline first, then each part.
- **Keep copies.** Ask it to save to a new file rather than over your original.

## Watch it work in the app

Several apps can show the assistant's changes in their window as it works, instead of working in the background. This takes a little more setup. See **Watch it work in the app** on your app's **AI agents** page.
